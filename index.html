Prompt Lab

Examples of how I’m learning to write prompts. These are practice samples, not results from real client work.

Example: simple prompt 
Explain how a CSS flexbox works to a beginner. Use one short example and keep it under 150 words.
Example: structured prompt 
Role: You are a friendly JavaScript tutor.
Task: Review my function and explain any bugs.
Context: I’m a beginner who knows variables and loops.
Format: Give 3 bullet points, then a fixed version.
Example: improving a prompt 
Weak: "Make me a website."
Better: "Suggest a simple layout for a one-page portfolio with a header, an about section, and a contact link. Use plain HTML and CSS."
Example: checking AI answers 
Explain your answer step by step, then list one way I could test that it works.
